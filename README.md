# Herdr Стенограф

Стенограмма всего, что звучит на компьютере: созвоны, вебинары, видео. Нажали «Начать стенограмму» в строке меню, в конце нажали «Остановить» – получили текстовый файл с отметками времени, который можно сразу отдать нейросети и попросить саммари.

Брат-близнец [Herdr Voice](https://github.com/Tenzen1231/Speak-Russian-Herdr-Voicer): тот же движок распознавания, но слушает не микрофон, а звук компьютера. Всё работает на вашем Mac: интернет, аккаунты и ключи не нужны, звук никуда не отправляется.

## Возможности

- **Звук компьютера без драйверов.** Используется системный механизм macOS (ScreenCaptureKit), как в Zoom и OBS. Ставить BlackHole и настраивать «Audio MIDI» не нужно. Работает и в наушниках.
- **Свой голос тоже.** Пункт «Записывать и мой микрофон» добавляет вашу речь. Тогда в файле видно, кто говорит: `Я:` и `Собеседники:`.
- **Точное распознавание русского.** GigaAM v3 от Сбера сама расставляет точки, запятые и заглавные буквы.
- **Часы записи.** Текст распознаётся по ходу и сразу дописывается в файл. В памяти держится не больше полуминуты звука, а если программа или Mac упадут, всё сказанное до этого уже на диске.
- **Mac не уснёт** посреди длинной встречи, пока идёт запись.

## Установка

| Система | Инструкция |
|---|---|
| **macOS** 13 и новее, Apple Silicon и Intel | [mac/README.md](mac/README.md) – одна команда в Терминале |

## Пример файла

```
Стенограмма 24.10.2026 14:30
Источник: звук компьютера и микрофон

[00:00:04] Собеседники: Коллеги, привет. Сегодня обсуждаем релиз.
[00:00:11] Я: Да, у меня два вопроса по срокам.
[00:02:47] Собеседники: Тогда фиксируем: выкатываем во вторник.

Длительность записи: 00:31:12
```

## Как это устроено

```
core/       движок: распознавание, определение речи, длинная стенограмма в файл
mac/        приложение для строки меню macOS: AppKit и ScreenCaptureKit через PyObjC, установщик
licenses/   лицензии моделей и библиотек
```

| Компонент | Что делает |
|---|---|
| ScreenCaptureKit | получает звук всех программ, кроме самого Стенографа |
| [GigaAM v3 E2E RNN-T](https://github.com/salute-developers/GigaAM) | распознаёт речь, int8, около 220 МБ |
| [onnx-asr](https://github.com/istupakov/onnx-asr) и ONNX Runtime | запускают модель на процессоре |
| [Silero VAD](https://github.com/snakers4/silero-vad) | находит паузы, чтобы резать запись по фразам |
| sounddevice | получает звук с микрофона, если он включён |

## Приватность

- Звук обрабатывается только в оперативной памяти и не сохраняется. На диск пишется только распознанный текст.
- Изображение экрана не используется: macOS выдаёт звук только вместе с «картинкой», поэтому программа просит крошечную картинку 2×2 точки раз в секунду и сразу её выбрасывает.
- В файле настроек хранятся папка для стенограмм, выбранный микрофон и путь к последней стенограмме.
- Сетевых запросов программа не делает. Интернет нужен только установщику, чтобы скачать библиотеки и модель.
- Перед записью чужой речи предупредите собеседников – так правильно и этично, а в ряде случаев этого требует закон.
