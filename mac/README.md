# Herdr Стенограф для macOS

Стенограмма звука компьютера в текстовый файл: значок волны в строке меню → «Начать стенограмму» → «Остановить и сохранить».

Подходит для macOS 13 Ventura и новее, на Apple Silicon (M1–M4) и Intel. Права администратора не нужны.

## Установка

1. Откройте **Терминал**: нажмите `Cmd + Пробел`, наберите «Терминал» и нажмите `Enter`.
2. Скопируйте команду, вставьте её в Терминал и нажмите `Enter`:

```bash
curl -fsSL https://raw.githubusercontent.com/Tenzen1231/Herdr-Scribe/main/mac/install.sh | bash
```

3. Подождите 3–5 минут. Установщик сам скачает Python, библиотеки и модель распознавания, соберёт приложение под ваш Mac и запустит его. Если на Mac уже стоит Herdr Voice, модель повторно не скачивается.

Приложение устанавливается в `~/Applications`. Автозапуск по умолчанию выключен, его можно включить в меню.

## Разрешения

| Разрешение | Где включить | Зачем |
|---|---|---|
| **Запись экрана и системного звука** | Системные настройки → Конфиденциальность и безопасность → Запись экрана → включить **HerdrScribe**, затем согласиться на перезапуск | слышать звук компьютера |
| **Микрофон** (по желанию) | «Разрешить» в окне запроса | только если включён пункт «Записывать и мой микрофон» |

Через «Запись экрана» macOS выдаёт программам и системный звук – отдельного разрешения только на звук в macOS 13–14 нет. Картинка экрана не сохраняется. macOS 15 может раз в месяц переспрашивать это разрешение – это поведение системы.

## Как пользоваться

1. Щёлкните по значку волны в строке меню сверху справа → **Начать стенограмму**.
2. Значок станет красным кружком, рядом пойдёт таймер. Через меню видно последнюю распознанную фразу – так можно убедиться, что запись идёт.
3. В конце: меню → **Остановить и сохранить**. Через несколько секунд откроется Finder с готовым файлом.
4. Отдайте файл нейросети: «Сделай краткое саммари встречи: решения, задачи, ответственные, сроки».

Файлы лежат в `Документы/Стенограммы`, имя – дата и время начала: `2026-10-24 14-30.txt`. Текст появляется в файле прямо во время записи, порядок строк окончательно выравнивается при остановке.

### Свой голос

Пункт **Записывать и мой микрофон** добавляет вашу речь с пометкой `Я:`, а звук компьютера помечается как `Собеседники:`. Включайте его **в наушниках**: через динамики микрофон услышит собеседников, и их слова попадут в файл дважды.

Многие программы для звонков (Zoom, Teams, Telemost) не выводят ваш собственный голос в динамики, поэтому без микрофона в стенограмме будет только речь собеседников.

## Меню

- **Начать стенограмму / Остановить и сохранить**.
- **Открыть последнюю стенограмму**, **Скопировать последнюю стенограмму** – чтобы сразу вставить текст в чат с нейросетью.
- **Показать папку стенограмм**.
- **Записывать и мой микрофон**, **Микрофон** – выбор устройства.
- **Папка…** – куда сохранять файлы.
- **Запускать при входе в систему**.
- **Выйти** – если идёт запись, она сначала сохраняется.

## Обновление

Запустите ту же команду установки ещё раз. После обновления macOS снова попросит разрешение «Запись экрана»: так устроена защита для приложений без подписи Apple.

## Удаление

```bash
curl -fsSL https://raw.githubusercontent.com/Tenzen1231/Herdr-Scribe/main/mac/uninstall.sh | bash
```

Удаляет приложение, настройки, автозапуск, кэш модели и выданные разрешения. Стенограммы остаются в папке.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| «Звука не было · проверьте разрешение» | Системные настройки → Конфиденциальность и безопасность → Запись экрана → включите HerdrScribe и перезапустите программу. Если включено, но не работает – выключите, удалите строку кнопкой «−» и запустите программу заново. |
| «Речь не обнаружена» | Звук был, но речи в нём нет. Проверьте, что звонок действительно звучит на этом Mac. |
| Нет моих реплик | Включите в меню **Записывать и мой микрофон** (в наушниках). |
| Мои реплики повторяются дважды | Вы говорите через динамики: наденьте наушники или выключите запись микрофона. |
| Рабочий Mac не даёт включить «Запись экрана» | Её блокирует политика компании. Нужно обратиться к администратору. |

## Где что лежит

| Путь | Что там |
|---|---|
| `~/Applications/HerdrScribe.app` | приложение |
| `~/Documents/Стенограммы` | стенограммы (папку можно сменить в меню) |
| `~/Library/Application Support/HerdrScribe/settings.json` | настройки |
| `~/Library/LaunchAgents/com.herdr.scribe.plist` | автозапуск, если включён |
| `~/Library/Caches/HerdrScribe-model` | кэш модели для переустановки |

## Сборка вручную

Если репозиторий уже скачан: `bash mac/install.sh`. Флаг `--no-launch` не запускает приложение после установки, `--autostart` сразу включает автозапуск.
